# Dokumente

Hier gehören zwei Dateien hin, die aus den Dokumenten in Claude exportiert werden:

| Datei | Quelle |
|---|---|
| `entwurf.md` | Dokument „Entwurf: Wettkampf-Tools mit zentraler Datenhaltung (BVBB)“ |
| `umsetzungsplan-etappe-1.md` | Dokument „Etappe 1 Umsetzungsplan Grundgeruest und Kaderliste“ |

So geht es: Dokument öffnen, im Menü „Herunterladen“ oder „Exportieren“ als **Markdown** wählen, Datei hier ablegen und umbenennen.

Vorher im Entwurf alle offenen Änderungsvorschläge annehmen oder ablehnen. Sonst steht in der Exportdatei ein Stand, der nicht mit dem Gespräch übereinstimmt.

Die Dateien enthalten keine Personendaten. Die echte Kaderliste und die Mitgliederliste gehören **nicht** in diesen Ordner und nicht in das Repository.
