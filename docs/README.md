# Dokumente

Geplant und spezifiziert wird im Claude-Projekt „BVBB-Wettkampf-Tools“, gebaut wird hier im Repository. Jedes Planungsdokument aus dem Projekt liegt zusätzlich hier, damit beide Entwicklungsrechner denselben Stand haben. Die Regel dazu steht in `CLAUDE.md` („Dokumente aus dem Planungsprojekt“).

Kommt im Projekt ein Dokument dazu, kommt hier eine Zeile dazu. Steht ein Projektdokument nicht in dieser Tabelle, fehlt es im Repository.

Ablage: Entwürfe nach `superpowers/specs/JJJJ-MM-TT-<thema>-design.md`, Umsetzungspläne nach `superpowers/plans/JJJJ-MM-TT-<thema>.md`, übergreifende Dokumente direkt in `docs/`. Inhalt unverändert übernehmen. Weicht eine Fassung von der anderen ab, nicht stillschweigend eine überschreiben, sondern beim Projektinhaber nachfragen.

Die Dateien enthalten keine Personendaten. Die echte Kaderliste und die Mitgliederliste gehören **nicht** in diesen Ordner und nicht in das Repository.
